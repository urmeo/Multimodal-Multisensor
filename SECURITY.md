# Security Policy

This repository holds research data and analysis notebooks. It runs no server, exposes no
service, and ships no secrets or API keys. The notebooks read committed CSVs and write
figures locally.

## Participant privacy

The study involved human participants. Only the case-study participant's raw streams are
included, with their consent; the remaining participants' raw recordings are deliberately
withheld and only aggregate summaries are published. If you believe any committed file
contains identifying information, please report it privately using the process below and it
will be removed promptly.

## Supported versions

Only the latest `main` is supported.

## Reporting a vulnerability

Please report privately rather than opening a public issue: use the repository's
**Security** tab, then **Report a vulnerability**, to open a private advisory.
